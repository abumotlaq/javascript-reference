# JavaScript Glossary

This glossary is a quick-reference dictionary for important JavaScript, DOM, BOM, and Web Platform terminology used throughout this repository.

The definitions are intentionally concise.

For a deeper explanation, use the linked documentation where available.

---

# A

## Abstraction

The process of exposing the important interface of a system while hiding unnecessary implementation details.

Related:

* Encapsulation
* Composition
* OOP

---

## AbortController

A browser and JavaScript API used to signal cancellation to APIs that support `AbortSignal`.

Commonly used with:

```js
const controller = new AbortController();

fetch(url, {
  signal: controller.signal,
});

controller.abort();
```

---

## AbortSignal

The signal associated with an `AbortController`.

It allows an operation to observe cancellation.

---

## API

Application Programming Interface.

A defined interface through which software can communicate with another system, library, service, or platform.

---

## Async Function

A function declared with `async`.

It always returns a Promise.

```js
async function loadData() {
  return "data";
}
```

---

## Asynchronous JavaScript

JavaScript programming in which an operation can complete later rather than blocking execution until it finishes.

Common mechanisms include:

* Callbacks
* Promises
* `async` / `await`
* Events
* Timers

---

## Await

An operator used inside an async function to wait for a Promise to settle.

```js
const result = await promise;
```

It does not block the entire JavaScript runtime.

---

# B

## BOM

Browser Object Model.

A practical term commonly used to describe browser-level objects and capabilities such as:

```text
window
location
history
navigator
screen
storage
```

The term is useful for learning, although modern browser APIs do not all belong to one formal BOM specification.

---

## Bubbling

An event propagation phase in which an event moves from the target element upward through its ancestors.

Typical order:

```text
Target
↓
Parent
↓
Ancestor
↓
Document
```

---

## Browser API

An API provided by the browser or Web Platform.

Examples:

* Clipboard API
* Geolocation API
* Notifications API
* Storage API
* History API
* Fetch API

---

# C

## Callback

A function passed to another function to be executed later or in response to an operation.

```js
function process(value, callback) {
  callback(value);
}
```

---

## Class

JavaScript syntax for defining objects through a constructor-based model built on top of the prototype system.

---

## Closure

A function together with access to variables from its surrounding lexical scope.

Closures allow functions to retain access to values after the outer function has finished executing.

---

## Composition

Building complex behavior by combining smaller independent pieces.

Composition is often preferred over deep inheritance hierarchies when appropriate.

---

## Constructor

A function or class method used to initialize a new object.

In a class:

```js
class User {
  constructor(name) {
    this.name = name;
  }
}
```

---

## Constructor Function

A traditional JavaScript function used with `new` to create objects before the introduction of the `class` syntax.

---

## Context

The surrounding execution information that affects how code behaves.

In discussions of `this`, "context" commonly refers to the object associated with the current function call.

---

## CORS

Cross-Origin Resource Sharing.

A browser security mechanism that allows a server to specify which cross-origin requests are permitted.

---

## CSRF

Cross-Site Request Forgery.

An attack in which a user's authenticated browser is tricked into sending an unintended request.

---

## CSP

Content Security Policy.

A response-header-based security mechanism that restricts which resources and behaviors a page is allowed to use.

---

# D

## Data Attribute

An HTML custom attribute beginning with `data-`.

Example:

```html
<button data-user-id="123">
  Open
</button>
```

Accessible through:

```js
element.dataset.userId;
```

---

## DOM

Document Object Model.

A programming representation of an HTML or XML document as a tree of nodes and objects.

---

## DOM Event

An event generated by user interaction, browser activity, or application behavior.

Examples:

```text
click
input
submit
keydown
focus
```

---

## Document Fragment

A lightweight DOM container used to construct or group nodes before inserting them into the document.

---

## Destructuring

Syntax for extracting values from arrays or objects into variables.

```js
const { name } = user;
```

---

# E

## Encapsulation

The practice of controlling access to internal implementation details and exposing a deliberate interface.

---

## Environment

The runtime context in which JavaScript executes.

Examples include:

* Browser
* Node.js
* Worker

Different environments provide different global APIs.

---

## Event Bubbling

See [Bubbling](#bubbling).

---

## Event Capturing

The phase in which an event travels from the higher-level document hierarchy toward the target element before reaching the target.

---

## Event Delegation

A pattern in which a parent element listens for events from its descendants instead of attaching listeners to every child individually.

---

## Event Loop

The runtime mechanism that coordinates synchronous JavaScript execution with queued asynchronous work.

---

## Event Object

The object passed to an event listener containing information about the event.

Common properties include:

```text
target
currentTarget
type
key
clientX
clientY
```

---

## Execution Context

An internal JavaScript concept describing the environment in which code executes.

Execution contexts contain information such as:

* lexical environment
* variable environment
* `this` value

---

# F

## Falsy

A value that becomes `false` when converted to Boolean.

Common falsy values include:

```text
false
0
-0
0n
""
null
undefined
NaN
```

---

## Feature Detection

Checking whether a capability exists before using it.

Example:

```js
if ("clipboard" in navigator) {
  // Use Clipboard API
}
```

This is generally preferable to guessing the browser from its user-agent string.

---

## Fetch API

A Web Platform API for making network requests.

Example:

```js
const response = await fetch("/api/data");
```

---

## Function

A reusable block of executable JavaScript code.

Functions can:

* receive arguments
* return values
* be assigned to variables
* be passed as values
* be returned by other functions

---

# G

## Garbage Collection

Automatic memory management performed by the JavaScript runtime.

Objects that are no longer reachable can eventually become eligible for collection.

---

## Getter

A special object or class accessor that runs when a property is read.

```js
get name() {
  return this._name;
}
```

---

## Global Object

The object associated with globally available JavaScript properties in a particular environment.

In modern cross-environment JavaScript, `globalThis` provides standardized access to the global object.

---

## GlobalThis

A standard way to access the global object across JavaScript environments.

```js
globalThis
```

---

# H

## Hash

The fragment portion of a URL after `#`.

Example:

```text
https://example.com/page#projects
```

The fragment is:

```text
#projects
```

---

## Higher-Order Function

A function that accepts one or more functions as arguments, returns a function, or both.

Examples include:

```text
map
filter
reduce
forEach
```

---

# I

## Immutable Data

Data that is not directly modified after creation.

Instead of changing an existing value, a new value is produced.

Immutability is especially important in state-management patterns.

---

## Inheritance

An OOP mechanism where one class or object derives behavior from another.

In JavaScript classes, inheritance is expressed with:

```js
extends
```

---

## Instance

A specific object created from a class or constructor function.

---

## Instance Method

A method associated with instances of a class.

```js
class User {
  greet() {
    return "Hello";
  }
}
```

---

## Iterator

An object that follows the iterator protocol and produces values through its `next()` method.

---

# J

## JavaScript

A programming language widely used for web development and also used in many non-browser environments.

JavaScript is standardized by ECMAScript.

---

## JSON

JavaScript Object Notation.

A text-based data format commonly used for structured data exchange.

Example:

```json
{
  "name": "Osama Abu Motlaq"
}
```

JSON is not identical to a JavaScript object.

---

# L

## Lexical Scope

The scope determined by where code is written rather than where a function is called.

Closures rely on lexical scoping.

---

## Local Storage

Browser storage that persists data across page reloads and commonly across browser sessions for the same origin.

Accessed through:

```js
localStorage
```

Values are stored as strings.

---

## Location

The browser object representing the current document URL and providing navigation-related operations.

Accessible through:

```js
window.location
```

---

## Logical Assignment

Assignment operators that combine logical operations with assignment.

Examples:

```js
x ||= value;
x &&= value;
x ??= value;
```

---

# M

## Map

A collection that stores key-value pairs.

Unlike ordinary objects, a `Map` can use many types of values as keys.

---

## Method

A function associated with an object.

Example:

```js
const user = {
  greet() {
    return "Hello";
  },
};
```

---

## Microtask

A queued unit of asynchronous work processed after the current JavaScript stack completes and before the browser proceeds to the next task/rendering opportunity in typical browser scheduling.

Promise reactions are commonly associated with the microtask queue.

---

## MutationObserver

A browser API used to observe changes to the DOM.

---

# N

## Navigator

A browser object that exposes information and capabilities associated with the browser environment.

Examples include:

```js
navigator.language
navigator.onLine
navigator.geolocation
navigator.clipboard
```

---

## Node

A fundamental object in the DOM tree.

Examples include:

* Element nodes
* Text nodes
* Document nodes

---

## NodeList

A collection-like object representing a list of DOM nodes returned by certain DOM APIs.

---

## Nullish

A value that is either:

```text
null
undefined
```

The nullish coalescing operator `??` checks for nullish values.

---

# O

## Object

A JavaScript value that can contain properties and methods.

---

## Object-Oriented Programming

A programming paradigm based on objects, state, behavior, and relationships between objects.

---

## Observer

A browser mechanism that watches for specific changes or conditions.

Examples include:

* MutationObserver
* ResizeObserver
* IntersectionObserver
* PerformanceObserver

---

## Origin

A combination of:

```text
scheme
host
port
```

Example:

```text
https://example.com:443
```

Origins are fundamental to browser security.

---

# P

## Parameter

A variable declared by a function that receives an argument when the function is called.

```js
function greet(name) {
  // name is a parameter
}
```

---

## Passive Event Listener

An event listener declared with:

```js
{ passive: true }
```

This tells the browser that the handler will not call `preventDefault()`.

---

## Permission

Browser-controlled authorization for certain capabilities such as:

* Geolocation
* Notifications
* Clipboard access
* Camera
* Microphone

Permission states often include:

```text
granted
denied
prompt
```

---

## Polymorphism

The ability for different objects or classes to provide different implementations of the same conceptual interface.

---

## Promise

An object representing the eventual completion or failure of an asynchronous operation.

A Promise has states such as:

```text
pending
fulfilled
rejected
```

---

## Prototype

An object from which another object can inherit properties and behavior.

JavaScript uses prototype-based inheritance.

---

## Prototype Chain

The sequence of prototype objects JavaScript follows when resolving a property or method.

---

# R

## RequestAnimationFrame

A browser API for scheduling a callback before the browser's next repaint opportunity.

Commonly used for visual updates and animation.

```js
requestAnimationFrame(update);
```

---

## REST Parameters

Syntax that collects remaining function arguments into an array.

```js
function sum(...numbers) {
  // ...
}
```

---

## `replaceState()`

A History API method that replaces the current history entry without creating a new one.

---

## `pushState()`

A History API method that adds a new history entry without performing a full document navigation.

---

## Referrer

Information about the previously visited page or source of a navigation/request.

Browsers can reduce or omit referrer information depending on policy and context.

---

## `requestIdleCallback`

A browser API that can schedule low-priority work during periods when the browser is idle.

It should not be treated as a guaranteed precise scheduling mechanism.

---

# S

## Scope

The region of code where a variable or binding is accessible.

Common JavaScript scope types include:

* Global scope
* Function scope
* Block scope
* Module scope

---

## Screen

A browser object containing information about the user's display environment.

Accessible through:

```js
window.screen
```

---

## Session Storage

Browser storage associated with a browser session context and an origin.

Accessed through:

```js
sessionStorage
```

---

## Shadow DOM

A DOM encapsulation mechanism associated with Web Components.

It is not the same as the regular document DOM.

---

## Spread Syntax

Syntax using `...` to expand iterable or object values in supported contexts.

Examples:

```js
const numbers = [1, 2, 3];

const copy = [...numbers];
```

and:

```js
const userCopy = {
  ...user,
};
```

---

## Static Method

A method defined on a class itself rather than on its instances.

```js
class User {
  static create() {
    return new User();
  }
}
```

---

## Storage API

Browser APIs for persistent or session-based key/value storage.

Examples:

```text
localStorage
sessionStorage
```

---

## Structured Clone

A browser/platform mechanism used by several APIs to copy many JavaScript values while preserving supported structure.

It is relevant to APIs such as:

* `structuredClone()`
* `postMessage()`
* some History API state
* other Web Platform features

---

# T

## Task

A unit of work scheduled for execution by the JavaScript runtime.

Examples may include:

* timers
* certain DOM events
* other queued callbacks

Task scheduling and microtasks are important parts of the browser event loop.

---

## Template Literal

A string literal using backticks that can contain interpolation and multiline text.

```js
const name = "Osama Abu Motlaq";

console.log(`Hello, ${name}`);
```

---

## Throttling

A technique that limits how often a function can execute during a period of repeated events.

Useful for:

* scroll
* resize
* pointer movement

---

## Timer

A browser API mechanism for scheduling callbacks.

Examples:

```js
setTimeout()
setInterval()
```

Timers are not exact real-time clocks.

---

## `this`

A JavaScript keyword whose value depends on how a function is called.

Its behavior differs between normal functions and arrow functions.

---

# U

## URL

Uniform Resource Locator.

A string representing the location of a resource and its addressing information.

The `URL` interface provides a structured way to work with URLs.

---

## URLSearchParams

An API for reading and manipulating URL query parameters.

Example:

```js
const params = new URLSearchParams(window.location.search);

const query = params.get("q");
```

---

## User Agent

Information historically exposed by browsers to identify the browser and environment.

User-agent information is increasingly constrained and should generally not be used as the primary mechanism for capability detection.

---

# V

## Virtual DOM

A framework concept in which a library such as React maintains a representation of UI structure and determines updates rather than requiring developers to manually manipulate every DOM change.

The virtual DOM is a React-related concept, not a browser API.

---

## Viewport

The visible area of a web page within the browser window.

It differs conceptually from the full physical screen.

---

# W

## Web API

An interface exposed by the browser or Web Platform to web applications.

Examples include:

```text
DOM APIs
Fetch API
Storage API
Clipboard API
Geolocation API
Notifications API
History API
```

---

## WeakMap

A collection of key-value pairs where keys are objects and references to keys do not prevent garbage collection.

---

## WeakSet

A collection of objects held weakly.

---

## Web Worker

A browser execution context that can run JavaScript outside the main page execution context.

Useful for suitable CPU-heavy work.

---

## Window

The top-level browser object associated with a page browsing context.

Example:

```js
window.innerWidth
```

---

## Worker

A general term for a background JavaScript execution context.

Examples include:

* Dedicated Workers
* Shared Workers
* Service Workers

They have different lifecycles and capabilities.

---

# X

## XSS

Cross-Site Scripting.

A class of vulnerability in which untrusted content is interpreted as executable script in a user's browser.

Safer rendering and output encoding are important defenses.

---

# Z

## Zero-Based Index

A numbering convention where the first item has index `0`.

Example:

```js
const names = ["Osama Abu Motlaq", "Developer"];

console.log(names[0]);
```

The first element is at index `0`.

| ---------------------- | ---------------------------------------------- |

# JavaScript Examples

This directory contains practical JavaScript examples corresponding to topics covered in the main documentation.

Each example is intentionally small and focused on demonstrating JavaScript code and browser APIs in a practical way.

## Structure

```text
examples/
├── 01-fundamentals/
├── 02-functions/
├── 03-async/
├── 04-oop/
├── 05-es6-features/
├── 06-dom/
├── 07-bom/
└── 08-web-platform/
```

## Usage

Many language-level examples can be executed with Node.js:

```bash
node path/to/example.js
```

Browser-dependent examples require a browser environment.

Some examples depend on browser features such as:

* DOM
* Browser APIs
* Web Platform APIs
* Service Workers
* Media Devices

These examples should be executed from a web page or a local development server when required.

Examples are intended to be run, modified, and experimented with.

For detailed explanations, refer to the corresponding documentation in the `docs/` directory.

docs/

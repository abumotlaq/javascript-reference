=# JavaScript Examples

This directory contains practical JavaScript examples corresponding to topics covered in the main documentation.

Each example is intentionally small and focused on demonstrating code.

## Structure

```text
examples/
├── fundamentals/
├── functions/
├── async/
├── oop/
├── es6-features/
├── dom/
└── bom/
```

## Usage

Most language-level examples can be executed with Node.js:

```bash
node path/to/example.js
```

Browser-dependent examples require a browser environment.

Examples are intended to be run, modified, and experimented with.

For detailed explanations, refer to the corresponding files in the `docs/` directory.

## Principle

```text
docs/
→ Explanation

examples/
→ Code

projects/
→ Practical applications
```

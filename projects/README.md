# JavaScript Projects

This directory contains complete JavaScript applications built by combining concepts covered throughout the reference.

Projects are larger and more integrated than the examples in the `examples/` directory.

## Purpose

The projects are designed to demonstrate how individual JavaScript concepts work together in realistic applications.

Each project may combine:

* JavaScript fundamentals
* Functions and modularity
* Asynchronous JavaScript
* DOM manipulation
* Browser APIs
* Web Platform APIs
* Data handling
* Error handling
* State management
* Application structure

## Structure

```text
projects/
├── 01-task-manager/
├── 02-weather-app/
├── 03-expense-tracker/
├── 04-quiz-app/
├── 05-github-user-search/
└── 06-mini-ecommerce/
```

Projects are organized from simpler applications to more advanced applications.

## Project Structure

A typical project may contain:

```text
project-name/
├── README.md
├── index.html
├── style.css
└── app.js
```

Larger projects may use additional files and directories when necessary.

## Execution

Projects that use only browser APIs can usually be opened through a local development server.

For example:

```bash
npx serve .
```

Projects that require a specific setup will document their requirements in their individual `README.md` files.

## Learning Principle

```text
docs/
→ Explanation

examples/
→ Focused code

projects/
→ Complete applications
```

The goal of each project is to demonstrate how JavaScript concepts are combined to build a working application rather than to teach a single isolated feature.

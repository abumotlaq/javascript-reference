# Task Manager

A small task management application built with HTML, CSS, and vanilla JavaScript.

The project demonstrates how core JavaScript concepts can be combined to build a complete browser application.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by status
- Clear completed tasks
- Persist tasks with `localStorage`
- Display task statistics
- Prevent empty task submission
- Restore saved tasks on page load

## Concepts Used

- Variables and constants
- Arrays and objects
- Functions
- Array methods
- Conditional logic
- DOM selection and manipulation
- Event handling
- Event delegation
- JSON
- Local Storage
- Error handling
- Modular function design

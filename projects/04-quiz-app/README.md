# Quiz App

A browser-based quiz application built with HTML, CSS, and vanilla JavaScript.

The application presents multiple-choice questions, tracks the user's progress, includes a countdown timer, calculates the final score, and allows the quiz to be restarted.

## Features

* Multiple-choice questions
* One answer per question
* Countdown timer
* Progress indicator
* Next question navigation
* Immediate answer feedback
* Final score calculation
* Percentage calculation
* Restart quiz
* Prevent accidental multiple submissions
* Responsive layout

## Concepts Demonstrated

* Arrays and objects
* Functions
* Array methods
* Conditional logic
* DOM manipulation
* Event handling
* Event delegation
* Timers
* `setInterval()`
* `clearInterval()`
* State management with variables
* Template literals
* Destructuring
* `Math`
* Date and time handling
* Dynamic rendering

## Running the Project

Open the project using a local development server.

For example:

```bash
npx serve .
```

Then open the provided local URL in your browser.

## Learning Goal

The goal of this project is to demonstrate how JavaScript can manage application state, user interaction, timers, dynamic DOM updates, and calculated results in a complete browser application.
